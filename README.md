# Study Tracker — Fullstack

Kevyt opintojen seurantaohjelma esimerkkiprojekti. Tämä varsinainen repo sisältää frontendin, backendin, tietokantaskriptit ja testit.

## Nopeasti käyntiin
- Backend: `uvicorn backend.main:app --reload`
- Frontend: avaa `frontend/index.html` selaimessa

## Rakenne
Katso projektin juurihakemisto, josta löytyy `frontend/`, `backend/`, `db/`, `docs/` ja `tests/`.
