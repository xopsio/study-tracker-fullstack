# commit notes

## standard commit message used

docs: finalize qodo workflow

## meaning (english)
- docs: the change affects documentation
- finalize: the content is complete and locked
- qodo workflow: specifies the document being finalized

## suomennos
- docs: muutos koskee dokumentaatiota
- finalize: sisältö on valmis ja lukittu
- qodo workflow: kertoo mitä dokumenttia muutos koskee

## usage rule
- this message is used when the qodo workflow document is completed
- do not reuse this message for other changes

## example command

git add docs/qodo_workflow.md  
git commit -m "docs: finalize qodo workflow"
